MethodologyGates first, then a fit score

Each opportunity passes eligibility gates first, then gets a weighted fit score out of 100. A model scorer sets the recommendation; a reviewer's score sits beside it and every disagreement is marked Split.

  • Legal eligibility. Relay is an allowed party for THIS instrument. GRANT path: allowed applicant type — nonprofit / IHE / graduate school / educator-prep provider (EPP) / eligible subrecipient/partner. VENDOR path (contract_procurement | cooperative_contract): Relay can be a PAID VENDOR for this service — a distinct test from grant applicant-type (see district_vendor_path below). If not met: No-go
  • Geography. Opportunity covers >=1 Relay jurisdiction OR is national/open to any eligible US nonprofit. If not met: No-go
  • Mission boundary. Purpose can reasonably fund teacher prep, educator pipeline, school leadership, certification, residency, educator diversity, high-need schools, or research/evaluation. If not met: No-go
  • Deadline feasibility. Full proposal due in <10 business days (or LOI <3 business days) without existing materials. If not met: Review
  • Match affordability. Mandatory match exceeds confirmed available match or creates audit risk (per 2 CFR 200.306: verifiable, allowable, not double-counted). If not met: No-go
  • Allowable use. Funds can support Relay's relevant activities/allowable costs (not restricted to uses Relay can't deploy). If not met: No-go
  • Source confidence. Primary source link present AND deadline/eligibility verifiable this run. If not met: Review

Fit dimensions and weights: mission program fit (18), eligibility match (14), financial value (12), program readiness evidence (10), effort deadline runway (10), win probability (10), geographic beneficiary fit (8), match compliance burden (8), funder relationship (5), strategic value (5).
