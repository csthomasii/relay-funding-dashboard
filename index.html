Help — reading the docket, shortcuts & team sync

Reading the docket

  • Go / Review — pursue now, or a human call is needed. Qualify — worth pursuing once a named unknown is resolved. Watch — monitor only. Screened out — kept as the audit trail, collapsed by default.
  • Fit is the 0–100 weighted rubric score. Red ink marks two things only: the ACTION REQUIRED count and stamp, and a business-day count of five or fewer. Everything else stays in plain ink.
  • Net-to-Relay flags money that never reaches Relay — ⚠ marks scholarship pass-throughs.
  • Amounts, deadlines and eligibility are verified from primary sources on the sitting date; anything unverified is labeled.
  • Dollars stated is the program pool or contract ceiling as the posting states it, summed over the matters that state one. A matter with no stated amount is counted, never estimated. The map places every matter in its state; federal competitions sit on the nationwide line. Click a state, or a line in the table under the map, to show only that place's matters.

Team sync — how it works

Stars, notes, and dismissals are shared with the whole team. They're stored in a small file that lives alongside this page on GitHub — no separate account or app. (What you've read is personal and stays on your own computer.)

Just browsing? Nothing to set up. You already see the team's stars and notes.

Want your changes to save for the whole team? You need a one-time "save key" from GitHub (free account required). It takes about two minutes:

  1. Sign in at github.com, click your photo (top-right) → Settings.
  2. Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Name it Funding Dashboard, set expiration to 90 days (you'll repeat this when it expires).
  4. Repository access: Only select repositories → relay-funding-dashboard.
  5. Permissions → Repository permissions: Contents: Read and write. Nothing else.
  6. Generate, copy the github_pat_… code, paste it below with your name, Save.
This dashboard's GitHub home is public, so notes are visible to anyone who finds it — keep them operational ("we should register for this"), never confidential. Your save key stays in this browser only and can only touch this one dashboard.
