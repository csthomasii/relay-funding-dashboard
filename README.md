# Relay Public Funding — Opportunity Dashboard

Static publication of the weekly Relay grant-finder dashboard, shared for
feedback with the public grants team. Working document — recommendations are
advisory, for human judgment.

- **Dashboard:** `index.html` (GitHub Pages)
- **Scoring rubric:** [`config/scoring.yaml`](config/scoring.yaml) — the
  hard gates + weighted fit dimensions every recommendation traces to.

Regenerated weekly by the relay-grant-finder pipeline; this repo carries the
published snapshot only (no fetcher code, no org-profile/district configs).
